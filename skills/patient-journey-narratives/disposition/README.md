# disposition

What the record shows around the end of treatment: the disposition event and its day, the milestones, when exposure ends, and the last adverse event recorded. At most four cited sentences. Use it from the control on the disposition lane. It quotes a recorded "discontinued due to adverse event" as the record's wording and never infers a reason. Inputs: `{ subject }`. Refuses with `refused:insufficient-data` when there are no disposition rows.
