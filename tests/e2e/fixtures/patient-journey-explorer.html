safety.viz Patient Journey Explorer demo

Demo and Playwright harness page for the patient-journey-explorer module (#142). Loads the committed IIFE bundle, then the hand-computed fixture dataset (patient-journey-explorer-data.js, which assigns window.PJE_FIXTURE), then mounts the six per-domain arrays. Every expected number the browser suite asserts lives in window.PJE_FIXTURE.expectations; nothing is pasted into the spec.
