safety.viz kit fixture

Playwright harness page for the kit (#154): what a second chart library on the page does. It loads the committed IIFE bundle and nothing else, and builds a working page from SafetyViz.kit alone — the shell with its sidebar, one filter, a bar chart drawn with kit.Chart, the record listing, and the participant rail opening from a listing row — against the fixture data in adbds.csv. It calls none of safety.viz's chart modules; the browser tests fail if it reads anything but kit from the bundle's global.
