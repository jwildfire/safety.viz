safety.viz Time-to-Event Explorer demo

Demo and Playwright harness page for the time-to-event module (#128). Loads the committed IIFE bundle against a small deterministic ADTTE fixture, engineered so every display path is exercised and every number is hand-checkable: a tied double event, an event and a censoring sharing a day, a curve that extends flat past its last event, a sparse second endpoint whose study-drug group is entirely censored (the flat-line case), three unusable rows (bad time, bad censor flag, duplicate participant), and a SEX column for the filter control.
